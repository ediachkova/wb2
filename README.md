# WB — Wild Profit

Аналитика прибыли для продавцов маркетплейсов (Wildberries / Ozon / Яндекс Маркет).
Дашборд, отчёты (анализ по номенклатурам, по неделям, P&L), справочники, реестры, настройки.

Светлая и тёмная темы. Интерфейс на русском.

---

## Запуск

Демо-вход: **demo@wildprofit.ru** / **demo1234**

> JSX компилируется в браузере через Babel standalone — удобно для разработки,
> но для продакшена стоит перейти на сборку (Vite/webpack), чтобы прекомпилировать
> код и убрать зависимость от CDN.

---

## Структура (что нужно для работы)

Модули (подключаются в этом порядке):

| Файл | Назначение |
|------|-----------|
| `shared.jsx`      | Тема, UI-компоненты, иконки, мок-данные, форматтеры |
| `layout.jsx`      | Сайдбар, шапка, навигация |
| `dashboard.jsx`   | Главный дашборд (KPI, графики) |
| `reports.jsx`     | Отчёты: фильтры, отчёт по неделям |
| `pnl.jsx`         | P&L (прибыли и убытки) |
| `nomenclature.jsx`| Анализ по номенклатурам (группы колонок, подсветка) |
| `sku-link.jsx`    | Связка карточек между маркетплейсами |
| `directories.jsx` | Справочники (номенклатура, статьи, себестоимость) |
| `settings.jsx`    | Настройки (профиль, API, нормы, уведомления) |
| `auth.jsx`        | Вход / регистрация |
| `registers.jsx`   | Реестры (операции, импорт) |
| `help.jsx`        | Обучение / поддержка |
| `app.jsx`         | Роутер, монтирование приложения |

Внешние зависимости (CDN, в репозиторий не кладутся):
React 18.3.1, ReactDOM, Babel standalone 7.29, prop-types 15.8, Recharts 2.12.7.
